# File-Kit: Universal File Converter & PDF Toolkit (Right-Click Integration)

## 🚀 Overview
File-Kit provides a context menu (right-click) extension for both Windows and Linux, allowing users to perform quick file operations such as:

- Convert files to PDF
- Convert files to DOCX
- Merge multiple PDFs into one
- Automatically delete original PDFs after merging (optional behavior)

All operations are accessible directly from the right-click menu.

---

## ✨ Features

### 📄 File Conversion
- Convert DOCX → PDF
- Convert Images → PDF
- Convert PDF → DOCX (basic support)

### 📚 PDF Merging
- Select multiple PDFs
- Merge into a single file
- Prompt user for output file name
- Automatically delete original files after merging

### 🖱️ Context Menu Integration
- Convert to PDF
- Convert to DOCX
- Merge PDFs

## 🛠️ Tech Stack

- Python 3.x
- PyPDF2 / pypdf
- python-docx
- Pillow
- docx2pdf
- pdf2docx

---


## ⚙️ Installation

git clone https://github.com/apatelpiyush/File-Kit.git
cd File-Kit

pip install -r requirements.txt

---

## 🧪 Usage

Right-click files and select desired operation.

---

## ⚠️ Notes

- Original PDFs deleted after merging
- Backup recommended
- Some conversions may lose formatting
